# Expense Tracker

A personal expense tracker that allows users to manage income and expenses while tracking their financial balance.

## Features
- Add income and expenses
- Edit and delete transactions
- Transaction history
- Category filtering
- Balance, Income and Expense summary
- Local Storage support
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage API
